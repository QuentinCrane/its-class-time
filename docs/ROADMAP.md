# ROADMAP｜原生客户端与发行路线图

截至 2026-11-28，v0.1.2 提供 Windows x64 离线 EXE 和 Apple Silicon 离线 DMG。当前 Windows 源码已加入九页设置、精确选时、EXE 登录启动和新增时钟选项。 [发行页面](https://github.com/QuentinCrane/its-class-time/releases/tag/v0.1.2) · [验收记录](ACCEPTANCE.md)

## M0 · 原生常驻与通知

| 能力 | Windows | macOS |
|---|---|---|
| 常驻入口 | 关窗后保留托盘。已实测键盘打开设置、隐藏和恢复组件。Explorer 重启待测。 | 应用包已通过启动冒烟。菜单栏关窗常驻与快捷操作待桌面验收。 |
| 浮窗 | 已核对四边吸附、置顶、首次显示和恢复时的输入焦点。 | AppKit 浮窗已构建。拖动、焦点与全屏 Spaces 待桌面验收。 |
| 即时通知 | 安装版已在通知中心核对合并消息，并验证关闭与恢复系统通知权限（T16、T21）。勿扰场景待测。 | 系统即时通知已接入。权限、投递与勿扰场景待桌面验收。 |

## M1 · 时间引擎

- 高中和大学预设、时间排序与重叠校验、进度、课程序号和下一边界均有双端引擎覆盖。Windows 270 项、macOS 220 项检查通过。
- Windows 安装版已实测在组件隐藏时发送通知。模拟恢复测试覆盖跳过中断期间旧边界并发送下一条通知。双端继续验收真实睡眠唤醒、连续跨午夜与时区变更。

## M2 · 作息编辑与桌面组件

| 能力 | 当前进度 |
|---|---|
| 三种桌面视图 | 双端已实现分节长条、圆环和屏幕边框，以及当前时段、全天范围和实时预览。Windows 已核对实际渲染、贴边与范围切换。macOS 待桌面复核。 |
| 作息编辑 | 双端提供自定义模板、今日覆盖、周/日课表和可缩放时间轴。Windows 九页设置已在 100%、125%、200% 缩放下核对。重复星期快捷项、滚动选时和计划范围已实测（T32、T34、T35）。 |
| 提醒与登录启动 | Windows 已核对暂停、恢复、通知权限、时钟样式和 EXE 登录项的登记与移除。真实注销登录及 macOS 登录启动待实测。 |
| 系统视觉与无障碍 | Windows 已核对三种缩放下的键盘操作并检查深浅色画面。双端继续验收系统对比度、读屏和 macOS 的 Liquid Glass 桌面表现。 |

## M3 · 稳定性与发行

| 能力 | 当前进度 |
|---|---|
| 多屏与全屏 | Windows 已验证双屏混合 DPI、普通无边框全屏隐藏与恢复、失效显示器 ID 回退。物理拔插、独占全屏和 macOS 多屏待测。 |
| 单实例与配置 | Windows 已实测第二实例唤起设置、退出、覆盖安装与损坏配置恢复。macOS 已通过单实例及坏配置恢复冒烟。 |
| 资源 | Windows 已采样从托盘打开设置的耗时，以及隐藏后的 CPU 与私有内存。唤醒次数、帧时间与 macOS 资源采样待补充。 |
| 双端发行 | GitHub Actions 构建两端并运行引擎检查。同一 Release 提供离线安装包和 SHA-256。Windows 代码签名、干净系统首次安装、macOS 公证与拖拽安装验收待完成。 |

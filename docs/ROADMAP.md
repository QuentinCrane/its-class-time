> 每个阶段都要在 macOS 和 Windows 两端完成对应验证；如其中一端暂无法测试，应明示“未验证”，不能称“全平台完成”。

> **Windows 进度备注（2026-11-21 第二轮）**：应用改为纯代码构建 WinUI 3（无 XAML 编译器依赖），新增 `IXamlMetadataProvider` 修复后，解包模式实机验证：进程稳定常驻、托盘图标、悬浮层渲染、设置窗口完整渲染均通过截图核对；通知实弹与 MSIX 打包仍未验证。构建与验证边界见 `windows/README.md`。

## M0：原生技术可行性验证

- [ ] macOS SwiftUI/AppKit 工程能运行，关闭设置仍常驻菜单栏。
- [ ] macOS 浮动进度条能显示、拖动、隐藏/恢复，不主动抢焦点。
- [ ] macOS 运行中可发送一次系统即时通知。
- [x] Windows C++/WinRT WinUI 3 工程能运行；后台托盘可靠。（解包模式实机运行通过，托盘图标已出现；explorer 重启重建未实测）
- [x] Windows HWND 浮窗能置顶并在关闭设置后保留。（置顶属性与渲染已实机截图核对；交互拖动/隐藏恢复待用户日常使用确认）
- [ ] Windows `AppNotificationManager.Show` 运行中发送一次系统即时通知。
- [ ] 两端观察全屏、屏幕缩放下的限制并记录。

**完成定义**：原生能力技术风险被验证，无跨平台库/服务。

## 已确定（不得擅自更改）

1. 双端纯原生：macOS Swift/SwiftUI/AppKit；Windows C++/WinRT/WinUI3/Win32。
2. 一个 GitHub Monorepo、两个独立工程、共同文档/预设/测试数据，不共享运行时业务库。
3. 用本地真实时钟的校园作息，而非单轮番茄钟；高中/大学是可编辑模板。
4. 悬浮时间显示：分节长条 + 圆环；两种范围：当前时段 + 全天。
5. 边缘悬浮、置顶、hover 详情；关闭设置不退出；菜单栏或托盘常驻。
6. 系统原生通知：**常驻进程到点判断、即时发送**，不排系统计划通知。
7. 今日单独覆盖 + 常规模板修改，**支持数字输入和滑动条**。
8. 午休/课间可调整，选择顺延后续或保持原位；冲突必须提示。
9. 提醒可暂停，时间不能暂停；睡眠唤醒不补发旧提醒。
10. 本地离线、低资源、避免账号/AI/数据库/服务/复杂依赖。

## 实现时的默认约定（允许基于实测微调，不得偷偷扩需求）

- 浮窗支持顶部/底部/左侧/右侧四条边吸附；左右贴边自动转为竖向排列，圆环保持圆形只改变停靠位置（2026-11-22 由“先做上下”扩展）。
- Windows 端可选视觉到点动效（四边柔光呼吸闪光、掉落放大 3D 电子/机械时钟）仅作为系统通知 `AppNotificationManager.Show` 之外的补充增强，统一由 `BoundaryMonitor` 到点判断与去重规则驱动，默认关闭、不抢焦点、绝不替代或绕过系统通知权限（2026-11-27 确认纳入）。
- 滑块默认按 5 分钟步进，精确值交给数字输入；具体滑块范围按编辑类型确定。
- 圆环先做单主环；是否增加辅环由 UI 可读性决定。
- 预设不是任何学校官方课表，用户可增删改。
- 默认“今日覆盖”只在当天有效；用户配置保存本地 JSON。
- Windows 首先用 WinUI 3 桌面打包模板；macOS 先在 Apple Silicon 构建，发行架构后再扩展。

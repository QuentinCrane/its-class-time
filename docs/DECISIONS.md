# DECISIONS｜产品与工程决策

> 本页记录产品与工程约定。调整已确定的决策时，先在 Issue 中讨论。

## 已确定

1. 双端纯原生：macOS Swift/SwiftUI/AppKit；Windows C++/WinRT/WinUI3/Win32。
2. 单仓库维护两个独立原生工程，共用 JSON Schema、预设与测试向量。
3. 作息随本地时钟运行，高中和大学是可编辑模板。
4. 桌面组件提供分节长条、圆环和屏幕边框，支持当前时段与全天范围。
5. 悬浮条与圆环支持贴边、置顶和悬停详情。关闭设置后，应用在菜单栏或托盘继续运行。
6. 常驻进程到达作息边界时即时调用系统通知。
7. 今日覆盖与常规模板各自保存，时长支持数字输入与滑动条。
8. 调整午休或课间时可选择顺延后续或保持原时间，冲突时指出对应时段。
9. 暂停提醒期间进度继续。恢复提醒或睡眠唤醒时重新计算下一边界。
10. 课表与设置保存在本机 JSON，应用离线运行。按实测记录 CPU、内存和唤醒次数。
11. 产品显示名为 **It's Class Time!（“上课”时间到！）**。工程与数据目录使用 `ClassTime` 标识。

## 默认行为

- 浮窗支持四边吸附。长条贴左右边时竖排，圆环在四边保持圆形。
- Windows 边缘柔光与放大时钟默认关闭。用户可独立启用，两种效果沿用与系统通知相同的边界与去重规则。
- 滑块默认按 5 分钟调整，数字输入精确到 1 分钟。
- 圆环使用单主环，全天范围补充显示已完成课节数。
- 预设提供可编辑样例，今日覆盖在对应日期生效。
- Windows 当前发行 x64 离线 EXE，最低 Windows 10 1809。macOS 当前发行 Apple Silicon 离线 DMG，最低 macOS 13。

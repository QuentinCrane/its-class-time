## 手工验收方式

1. **加速验证提醒**：不要改系统时间作为唯一测试手段，允许在测试环境中加载一个几分钟长的临时样例；正式应用仍按实际时间运行。
2. **事件去重**：在课程下课与短课间开始同一边界确认仅出现一个合并通知。
3. **系统限制**：以“普通窗口置顶 + 有系统全屏例外”为验收边界；不得用私有 API 为了绝对置顶破坏兼容性。
4. **跨端一致性**：使用相同 `shared/test-cases`；留存每条向量测试结果，不能只按截图判断。
5. **资源记录**：注明 OS 版本、CPU、显示器数量、进度显示模式、观测时长，记录闲置时 CPU/内存与是否过量频繁唤醒。

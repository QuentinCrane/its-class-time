## It's Class Time! v0.1.2

把一天的课表节奏放在桌面边缘。这个版本更新了 Windows 的显示选项与可选视觉提醒，同时整理了双平台安装包和项目介绍。

### 本次更新

- **Windows 显示**：可自定义上课、课间和午休的颜色，调整屏幕边框的渐变与进度高光，并按需设置全屏隐藏和任务栏覆盖。
- **Windows 视觉提醒**：可选择到点时的边缘柔光或放大时钟，并调整样式、位置与颜色。视觉动效默认关闭，与系统通知共用边界判断，不影响课表进度。
- **发行体验**：Windows 和 macOS 安装包的文件名现在清楚标示版本、系统与架构；README 与宣传图同步更新。
- **macOS**：继续提供 Apple Silicon 原生安装镜像；上述新增视觉提醒和部分显示选项目前仅在 Windows 提供。

### 下载与安装

| 平台 | 下载文件 | 系统要求 |
| --- | --- | --- |
| Windows x64 | `ItsClassTime-0.1.2-Windows-x64-Setup.exe` | Windows 10 1809 或更新版本 |
| macOS Apple Silicon | `ItsClassTime-0.1.2-macOS-arm64.dmg` | macOS 13 或更新版本 |

Windows 安装程序未进行代码签名，可能触发 SmartScreen 提示。macOS 应用使用 Ad-hoc 签名，尚未经过 Apple 公证，首次打开可能需要在「系统设置 → 隐私与安全性」中允许。安装包的 SHA-256 值见 `SHA256SUMS.txt`。

应用及课表配置保存在本机；升级不会主动删除已有课表。系统通知、睡眠唤醒及部分桌面交互仍需进一步实机验证，详见仓库中的 [验收记录](https://github.com/QuentinCrane/its-class-time/blob/main/docs/ACCEPTANCE.md)。

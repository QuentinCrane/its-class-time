# PRD｜产品需求文档

> It's Class Time!（“上课”时间到！）桌面作息产品规格，更新于 2026-11-28。时间计算与提醒规则见 [功能规格](FRD.md)。

## 1. 定位

**在桌面边缘显示当前是第几节、已进行多久、何时进入下一段。** 应用面向按课表学习、办公和安排休息的用户，作息随本地时钟运行。

优先让用户看清时间，其次保证到点提醒和作息调整顺畅。

## 2. 明确目标

| 编号 | 需求 | 可验证结果 |
|---|---|---|
| P01 | 高中/大学两种预设 | 首启可任选，之后可继续修改 |
| P02 | 作息灵活配置 | 课程/课间/午休起止与时长均能编辑 |
| P03 | 今日计划与常规模板 | 两者各自保存，今日调整在对应日期生效 |
| P04 | 数字输入 + 滑动条 | 可用输入精确调整、滑动方便微调 |
| P05 | 分节长条、圆环、屏幕边框 | 三种视图共享同一份作息和进度 |
| P06 | 当前时段/全天范围 | 选择后信息量相应改变 |
| P07 | 屏幕边缘常驻 | 关闭设置后，组件和托盘或菜单栏继续运行 |
| P08 | 原生系统通知 | 上下课/课间/午休边界触发即时通知 |
| P09 | 暂停提醒 | 暂停时进度继续，恢复后从下一边界提醒 |
| P10 | 睡眠恢复 | 唤醒时按当前时钟重算进度和下一边界 |
| P11 | 纯原生、低开销 | 双平台单独原生实现、离线运行 |

## 3. 关键使用流程

### 3.1 第一次使用

1. 打开设置，在「作息计划」选择高中或大学模板。也可复制现有模板或从空白作息开始。
2. 看到默认日程表，必要时编辑上课时间、课时、短课间、午休。
3. 在「显示与位置」选择分节长条、圆环或屏幕边框，再设定显示范围和显示器。
4. 在「通知」页查看系统权限及提醒时机，按需启用系统通知。
5. 关闭设置窗口后，从 macOS 菜单栏或 Windows 托盘控制组件与提醒。

### 3.2 每日使用

- 屏幕边缘的一排小条表示每节课程的进度。课间与午休通过间隔/独立休息标记区分。
- 当前课时增强对比度；已过课时完整填充；未来课时未填充。
- Hover 查看名称、第几节、起止、已过/剩余、百分比与下一时段。
- 当课程/休息状态发生变化，**当前常驻进程**主动通过操作系统通知接口发出提醒。
- 从托盘或菜单栏切换视图和显示范围、隐藏或显示组件、暂停或恢复提醒、打开设置或退出。

### 3.3 改午休

- 例如把午休由 `12:00—13:30` 改为 `12:00—14:00`。
- 可手动输入精确时间/分钟，也可用滑动条方便调整；不同输入方式保持同步。
- 选择「仅今天」或「永久修改模板」。
- 若修改影响后续时段，选择「顺延后续」或「后续保持原时间」。根据冲突提示调整后保存。
- 当前进度与下一提醒边界立即重算。

| P0 | 数字输入与滑动条 | 互相同步，可精确到分钟 |
| P0 | 圆环视图 | 显示当前课时进度和剩余时间 |
| P0 | 屏幕边框 | 沿屏幕四边显示进度，全天视图可按时段分色 |

| P0 | 暂停提醒 | 时间仍前进，图形仍更新 |

## 5. 平台与数据

当前发行覆盖 Windows x64 和 Apple Silicon Mac。应用在本机运行，作息与设置以本地 JSON 保存。首版范围按本页需求表执行，扩展议题在 [路线图](ROADMAP.md) 中维护。

## 6. 非功能目标

- macOS 采用 SwiftUI 与 AppKit，Windows 采用 C++/WinRT、WinUI 3 与 Win32。
- 应用可离线使用。配置恢复时保留故障原件，读写失败时提示原因。
- 使用各平台的系统字体、强调色与深浅模式。
- 悬浮组件在普通窗口上方显示，保留前台应用的输入焦点，支持主动隐藏和恢复。
- 记录闲置 CPU、内存、唤醒次数与重绘频率。
- 系统通知依照权限和勿扰设置呈现。应用的通知页显示权限状态。

## 7. 成功验收

在 macOS 与 Windows 11 上离线完成预设选择、进度查看、午休编辑、今日与模板核对、视图切换、通知、暂停提醒、睡眠唤醒和退出。结果记入 [验收记录](ACCEPTANCE.md)。

# PRD｜产品需求文档

> It's Class Time!（“上课”时间到！）v1.0｜2026-11-21｜范围：macOS + Windows 11 首版
>
> **这份文档回答**：为谁做、解决什么场景、哪些是 P0、哪些明确不做。具体到“几点算下课”“通知怎么去重”请看 [FRD.md](FRD.md)。

## 1. 定位

**让用户在一整天中持续感知“第几节、进行到哪里、多久后休息”，而非靠主动开启一轮一轮的番茄钟。** 用户核心场景是久坐办公、写代码、阅读、学习，对大块时间缺少感知。

设计价值优先级：**一眼读懂时间 > 可靠提醒 > 便利调整 > 视觉装饰**。

## 2. 明确目标

| 编号 | 需求 | 可验证结果 |
|---|---|---|
| P01 | 高中/大学两种预设 | 首启可任选，之后可继续修改 |
| P02 | 作息灵活配置 | 课程/课间/午休起止与时长均能编辑 |
| P03 | 今日与常规模板分离 | 今日修改不污染其他日期 |
| P04 | 数字输入 + 滑动条 | 可用输入精确调整、滑动方便微调 |
| P05 | 分节长条与圆环 | 两种视图共享当前课时进度数据 |
| P06 | 当前时段/全天范围 | 选择后信息量相应改变 |
| P07 | 屏幕边缘常驻 | 不遮挡主要内容、不随设置窗口关闭退出 |
| P08 | 原生系统通知 | 上下课/课间/午休边界触发即时通知 |
| P09 | 暂停提醒 | 关提醒不影响进度、可随时恢复 |
| P10 | 睡眠恢复正确 | 跳过已过期提醒，不乱报、不漂移 |
| P11 | 纯原生、低开销 | 双平台单独原生实现、离线运行 |

## 3. 关键使用流程

### 3.1 第一次使用

1. 打开应用，选择「高中模式」或「大学模式」。
2. 看到默认日程表，必要时编辑上课时间、课时、短课间、午休。
3. 默认启用「分节长条 / 当前时段」；也可选择「全天」或「圆环」。
4. 选择桌面悬浮位置，授权系统通知（拒绝也能使用计时/展示）。
5. 设置窗口可以关闭；应用通过 macOS 菜单栏或 Windows 托盘持续运行。

不做复杂向导，用一个设置窗口完成首启配置。

### 3.2 每日使用

- 屏幕边缘的一排小条表示每节课程的进度。课间与午休通过间隔/独立休息标记区分。
- 当前课时增强对比度；已过课时完整填充；未来课时未填充。
- Hover 查看名称、第几节、起止、已过/剩余、百分比与下一时段。
- 当课程/休息状态发生变化，**当前常驻进程**主动通过操作系统通知接口发出提醒。
- 打开托盘/菜单栏可：切换显示范围、切换视图、显示/隐藏组件、暂停/恢复提醒、打开设置、退出。

### 3.3 改午休

- 例如把午休由 `12:00—13:30` 改为 `12:00—14:00`。
- 可手动输入精确时间/分钟，也可用滑动条方便调整；不同输入方式保持同步。
- 明确选择「仅今天」或「保存到常规模板」。
- 若修改影响后续时段，提供「顺延后续」和「后续保持原时间」两个选项，预览冲突后保存。
- 当前进度与下一提醒边界立即重算。

## 4. 核心功能范围

| 优先级 | 功能 | 约束 |
|---|---|---|
| P0 | 作息时间引擎 | 本地时钟 + 半开区间；禁止重叠 |
| P0 | 后台常驻 | 应用进程而非系统服务，窗口隐藏不退出 |
| P0 | 系统即时通知 | 不使用系统预先计划排程，不补发过期通知 |
| P0 | 桌面浮条 + Hover | 分节进度、边缘吸附、可恢复 |
| P0 | 预设与本地保存 | 高中/大学只是可编辑初始模板 |
| P0 | 两层调整 | 今日覆盖 / 修改模板 |
| P0 | 数字输入与滑动条 | 互相同步，可精确到分钟 |
| P0 | 圆环视图 | 当前课时比例；不依赖 WebView |
| P0 | 当前时段/全天切换 | 两种范围，不额外增加第三种显示模式 |
| P0 | 暂停提醒 | 时间仍前进，图形仍更新 |
| P0 | 防重复/睡眠校正 | 不连续补报旧铃声 |
| P1 | 更多边缘/更精细动画 | 不阻断首次可用版本 |

## 5. 明确不做

账户、云同步、在线协作、AI、待办任务、日历同步、项目管理、复杂统计报表、白噪音、游戏化、移动 App、浏览器版、跨语言共享运行时库、后台服务器、Windows Service、LaunchDaemon。

铃声可以保留为未来开关，但**V1 核心依赖系统通知**，不假定用户允许声音或系统通知必然弹出。

## 6. 非功能目标

- 原生：macOS SwiftUI/AppKit、Windows C++/WinRT/WinUI3/Win32。
- 本地离线；配置文件可备份；失败可诊断。
- 外观使用系统字体、强调色、深浅模式；不追求两端设置窗口逐像素相同。
- 正常使用时极低打扰；悬浮条不抢焦点；可以显式隐藏、恢复。
- 不凭空承诺内存 MB 上限；测量闲置 CPU、内存、唤醒次数、重绘频率，并优化明显异常。
- 允许系统勿扰/权限限制导致通知不显示；应用需在设置界面清楚标注权限状态。

## 7. 成功验收

在 macOS 与 Windows 11 上完成相同流程：首启预设 → 看进度 → 改午休 → 看今日与模板差异 → 模式切换 → 通知 → 暂停提醒 → 睡眠唤醒 → 恢复进程 → 退出。不得出现需要联网或安装浏览器内核的步骤。
